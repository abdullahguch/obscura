# Contributing

Obscura is a copy-paste library. Treat every component as something someone will read.

1. Match the existing visual language: stamp shadows, catalog labels, safelight for signal.
2. Prefer native HTML and ARIA over extra dependencies.
3. Add a live demo in `src/site/demos.tsx` and a registry entry in `src/site/registry.ts`.
4. Keep the public API small and obvious.

```bash
npm run dev
npm run lint
npm run build
```
